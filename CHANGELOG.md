## [1.0.0] — 2025-02-13
### 🎉 Versión inicial del sistema (Release Estable)
- Implementación completa del sistema de turnos en tiempo real.
- WebSockets con **Laravel Reverb + Laravel Echo**.
- Modos claro/oscuro con Alpine.js.
- Vista **/kiosco** para emisión de turnos.
- Vista **/puesto** para gestión de turnos (llamar, atender, re-llamar, cerrar, ausente).
- Asignación de módulos (1–5) a cada turno.
- Vista **/pantalla** estilo TV con actualizaciones instantáneas.
- Sonido “ding.mp3” al llamar turnos.
- Migraciones y seeders completos.
- Frontend profesional con Tailwind CSS + Vite.
- README completamente documentado.
